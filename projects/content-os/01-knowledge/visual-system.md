# Content OS visual system

## Allowed metaphors

The source favors OS/stack layers, production pipelines, controlled factory environments, dashboards, chaos-to-control comparisons, and grids that demonstrate batching/versioning.

## Banned metaphors

It rejects generic AI robots/brains/neon, output collages without pipeline context, purely aesthetic slides without mechanisms, and agency-style mood boards.

## Color and motion

Visuals should use neutral, tech-forward palettes with a restrained accent for gates, alerts, or metrics. Motion should explain flow, stacking, or gate transitions; short demos should show the pipeline or batch run, not only the final asset.
