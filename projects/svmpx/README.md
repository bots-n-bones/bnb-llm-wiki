# SVMPX Knowledge Index

SVMPX is the pilot for the hybrid Drive + Markdown knowledge architecture.

## Sections

- `00-canon/` — candidates for current truth; only pages with
  `status: active` and `canonical: true` are approved.
- `01-knowledge/` — curated reusable knowledge and research.
- `02-decisions/` — approved and proposed decisions.
- `03-sops/` — operating procedures.
- `04-source-register/` — one record per important Drive source.
- `90-derived/` — machine-generated text with provenance.
- `99-archive/` — superseded Markdown retained for history.

## Pilot constraints

- The legacy SVMPX folders on Drive remain unchanged.
- A Drive document is not canonical merely because it is newer.
- Duplicate candidates are quarantined in the manifest, not deleted.
- Canonical status requires owner approval.
